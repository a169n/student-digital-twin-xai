# Problem Statement

Teachers need timely, interpretable insight into student progression, not only retrospective analytics.

Traditional dashboards often aggregate metrics without modeling a student's dynamic state trajectory. This project explores a **student digital twin** paradigm with XAI-supported predictions to enable early intervention decisions.

## Core Research Questions (Draft)
1. Can a digital-twin representation improve early `risk_level` detection quality?
2. How well can `final_grade` be estimated while preserving interpretability?
3. Which explanation forms best support teacher intervention planning?
