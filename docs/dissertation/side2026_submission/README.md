# SIDe 2026 submission package

`main.tex` is the manuscript of record. `docs/dissertation/side2026_paper.md` is
the superseded drafting master and its numbers are stale; do not cite from it.

## Build

The paper uses the standard IEEE conference class, which ships with TeX Live,
MiKTeX and Overleaf, so no template file needs downloading.

    latexmk -pdf main.tex

Or upload this whole folder to Overleaf (New Project → Upload Project) and set
`main.tex` as the main document. Overleaf compiles it as is.

## Before submitting — checklist

- [ ] Page count is 4–6 including references (conference rule counts everything).
      If it runs over, cut in this order: Related Work paragraph 2, the
      Sensitivity subsection, then the second and third controls.
- [ ] Decide anonymity BEFORE building. `main.tex` sets `lindfalse`, so the
      current PDF and .docx carry author names, affiliations, ORCIDs and emails.
      If SIDe 2026 reviews double-blind, change that one line to `lindtrue`,
      rebuild both, and check the front page and the Reproducibility sentence:
      both switch together, and the .docx builder reads the same flag.
- [ ] With names shown, replace `<repository URL>` in Reproducibility with the
      real link before submitting.
- [ ] Upload the anonymised repository and link it from the submission record.
      The Reproducibility section promises the adapters, cohort definitions,
      experiment code, frozen results and the verification script.
- [ ] Decide how the frozen results get released. `.gitignore` ignores `*.csv`,
      so they are currently untracked. Verification needs 14 files, about
      9.8 MB, the largest being exp_014/f33/pairs.csv at 9.4 MB. Either
      force-add those, or narrow the ignore rule to the directories that hold
      raw data rather than results.
- [ ] Export a searchable PDF with embedded fonts (the conference requires both).
      Every font in the PDF must carry a subset prefix; check with
      `pdffonts main.pdf`, or in Python with `fitz` if pdffonts is unavailable.
- [ ] Submit at https://cmt3.research.microsoft.com/SIDE2026 by 10 September 2026.
- [ ] Max 6 authors; one author may submit up to 3 papers.

## Provenance of every number

Every number in the paper is recomputed from a released artifact. Run

    cd services/ml && uv run python scripts/verify_paper_claims.py

It recomputes each claim from the frozen result files and reports whether the
manuscript states that value. `ABSENT` means the value is not written down,
which is often deliberate; a value stated differently in the text is the error
this catches.

Cohort definitions changed on 6 September 2026: a student enrolled in two
parallel sections of one course was entering a cohort twice, so `cutoff_rows`
now deduplicates. Every experiment downstream of the cohort definitions was
rerun against the corrected cohorts.
