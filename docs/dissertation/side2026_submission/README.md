# SIDe 2026 submission package

`main.tex` is the manuscript of record. `docs/dissertation/side2026_paper.md` is
the superseded drafting master and its numbers are stale; do not cite from it.

## Build

The paper uses the standard IEEE conference class, which ships with TeX Live,
MiKTeX and Overleaf, so no template file needs downloading.

    latexmk -pdf main.tex

Or upload this whole folder to Overleaf (New Project → Upload Project) and set
`main.tex` as the main document. Overleaf compiles it as is.

## Round-1 revision, what changed and why

Reviewer 4's eight points are answered in `response_to_reviewers.md`. The one
that matters for anyone reusing the numbers: the "cost of one year" in Table III
was, in the submitted version, a 63-cohort self-agreement mean minus a 78-pair
next-year mean. Referenced per pair to the cohorts of that pair it is 0.129
(SHAP) and 0.173 (permutation), not 0.083 and 0.089, and the level shift of
0.252 is 1.7 times the effect, not three. The abstract, Section V-C, Table III
and the conclusion carry the corrected figures.

## Provenance of every number

Every number in the paper is recomputed from a released artifact. Run

    cd services/ml && uv run python scripts/verify_paper_claims.py

It recomputes each claim from the frozen result files and reports whether the
manuscript states that value. `ABSENT` means the value is not written down,
which is often deliberate; a value stated differently in the text is the error
this catches.

Cohort definitions changed on 6 September 2026: a student enrolled in two
parallel sections of one course was entering a cohort twice, so `cutoff_rows`
now deduplicates. Every experiment downstream of the cohort definitions was
rerun against the corrected cohorts.
