# Data Model Scope

## Purpose
Define a versioned, evolvable data model for a student digital twin system focused on educational risk detection and explainable decision support.

## Current Scope
- Structural placeholders for entities and events.
- Targets: `risk_level`, `final_grade`, derived `passed`.
- Synthetic LMS-like source assumptions.

## Non-goals (Current Iteration)
- Final field-level constraints.
- Institution-specific policy encoding.
- Cross-institution ontology standardization.
